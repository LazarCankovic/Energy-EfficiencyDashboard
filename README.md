# Energy-EfficiencyDashboard
# Lazar Cankovic
# Project Description:
This project is a Python based dashboard that gathers and analyzes energy and sustainability data from the interet. By gathering data and storing it locally, dashboard shows detailed analysis of trends over time. This enables users to see electricity usage and energy statistics from the line and bar charts. The interface allows users to interact with the data.Goal of the project is to make energy data easy to understand.
# Project Outline:
## Interface Plan:
This app uses Flask for the web interface, where the home page will allow the user to click and select the buttons that determine the region and the energy metric. The second page will display the visualizations and statistics calculated. Interface includes dropdowns, buttons, and charts for the user to interact.
# Data Collection and Storage Plan:
The data is being collected from publicly available electricity usage and renewable energy dataset. Raw data is locally saved in CSV files, and then it would get preprocessed to a clean dataset for analysis.
# Data Analysis and Visualization Plan:
The Visualization consists of one time-series line plot.The analysis explains the patterns such as renewable energy share or average energy use per regions.
